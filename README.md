# Decathlon-Diak
A webapp that uses a spread sheet that is shared across the student employeed as a database and provides better view and control on the information with:

- [x] single employee perspective
- [x] daily shift info
- [x] monthly summary and analyitics
- [x] automatic shift syncing to google calendar
- [ ] user defined notification (discord/email) methods for the changes/events in the database (created, deleted, taken, released shifts)
- [ ] automatic work shift assignment with custom priorities

# Decathlon Diak

A webapp that gives student employees more detailed view on their shifts from the shared google sheet.

## Features
- [ ] Employee dashboard
    - [ ] Daily shift details
    - [ ] Monthly performance summary
- [ ] Leaderboard
    - [ ] Per-student ranking by performance stats
    - [ ] Aggregate stats across all students
- [ ] Google Calendar sync
    - [ ] Shifts pushed as calendar events
    - [ ] Automatic, continuous syncing
- [ ] Shift change notifications
    - Events: created, deleted, taken, released
    - Channels: Discord webhook, email
- [ ] Automatic shift assignment *(experimental, high risk)*

## Dev dependencies
- [clasp](https://github.com/google/CLASP)
